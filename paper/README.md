## Abstract

This paper presents a comparative study of classical and ensemble machine learning techniques for detecting hallucinated responses in Large Language Model outputs using the HaluEval benchmark dataset. A balanced dataset of 4,000 question-answer instances was constructed and transformed into TF-IDF feature vectors. Five supervised learning algorithms — Logistic Regression, Random Forest, XGBoost, LightGBM, and CatBoost — were trained and evaluated. XGBoost achieved the highest accuracy of 92.75%, while Random Forest led on AUC (0.967). The study establishes a reproducible, computationally efficient baseline and highlights the limitations of lexical-only features in capturing deep semantic inconsistencies.
